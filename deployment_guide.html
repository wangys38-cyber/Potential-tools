1 环境准备

部署前需要安装以下软件（如已安装可跳过）：

软件版本要求下载地址
Python3.10+https://www.python.org/downloads/
Git任意版本https://git-scm.com/download/win
安装 Python 时注意 勾选 "Add Python to PATH" 选项，否则命令行无法识别 python 命令。

2 一键部署（推荐）

本项目附带一键部署脚本 deploy_D_drive.bat，双击即可完成全部部署。

使用方法 双击运行 deploy_D_drive.bat，脚本会自动完成：创建目录 → 克隆代码 → 创建虚拟环境 → 安装依赖 → 安装Chromium → 生成启动脚本

部署完成后，双击 start_app.bat 即可启动应用。

部署结果 代码目录：D:\Potential-tools
访问地址：http://localhost:5001

3 手动部署

如需手动操作，按以下步骤执行：

3.1 克隆代码

:: 打开命令提示符 (Win+R 输入 cmd)
cd D:\
git clone https://github.com/wangys38-cyber/Potential-tools.git
cd Potential-tools

3.2 创建虚拟环境

python -m venv venv
call venv\Scripts\activate.bat

3.3 安装依赖

pip install -r requirements.txt

3.4 安装 Playwright Chromium（PDF功能需要）

playwright install chromium
注意 Chromium 安装包约 150MB，下载时间取决于网络速度。如果跳过此步，PDF转换功能将不可用，其他功能正常。

4 配置说明

4.1 访客模式（本地推荐）

本地使用无需配置 OAuth，开启访客模式即可访问所有功能：

:: 在启动前设置环境变量
set ALLOW_GUEST=true
python app.py

4.2 OAuth 登录（可选）

如需飞书/Google 登录，编辑 config_oauth.json：

{
  "feishu": {
    "app_id": "你的飞书AppID",
    "app_secret": "你的飞书AppSecret",
    "redirect_uri": "http://localhost:5001/auth/feishu/callback"
  },
  "allow_guest": true
}

4.3 环境变量

变量名默认值说明
PORT5001服务监听端口
ALLOW_GUESTfalse是否允许访客访问
DB_DIR/tmp/toolbox数据存储目录（Windows下建议改为项目目录）
SESSION_SECRETdefault_secretSession加密密钥

6 常见问题

Q: 端口 5001 被占用？

set PORT=8080
python app.py

Q: pip install 报错？

尝试升级 pip 后重装：

python -m pip install --upgrade pip
pip install -r requirements.txt

Q: Playwright 安装失败？

手动指定镜像源安装：

set PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright
playwright install chromium

Q: PDF转换功能不工作？

确保已安装 Chromium：运行 playwright install chromium。如仍失败，检查系统是否缺少 Visual C++ 运行库。

Q: 数据存储在哪里？

默认存储在 /tmp/toolbox/。Windows 建议设置 DB_DIR 环境变量指向项目目录：

set DB_DIR=D:\Potential-tools\data
python app.py
