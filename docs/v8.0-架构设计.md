# Potential-tools v8.0「AI 原生」架构设计

## 版本目标
从"工具集合"升级为"智能研发助手"，AI 深度融入每个工作流。

## 开发阶段

### Phase 1: AI 基础设施（当前）
- AI 服务抽象层（多提供商：OpenAI/Doubao/本地）
- AI 配置管理（API Key 加密存储、模型选择）
- 基础对话 API
- Prompt 模板管理

### Phase 2: 自然语言查询
- NL2SQL 引擎（自然语言转 SQL）
- 数据查询 + AI 解释
- 支持的表：用户数据、活动日志、审计日志

### Phase 3: CR 分析 AI 增强
- 智能归因（Bug 激增原因分析）
- 趋势预测（基于历史数据）
- 修复优先级建议

### Phase 4: AI Agent 工作流
- 多步骤任务编排
- 工具调用（内部 API）
- 自动分析报告

### Phase 5: 智能报告 & 推送
- 自动日报/周报生成
- 多格式输出（HTML/PDF/邮件）
- 定时推送（飞书/邮件）

### Phase 6: 跨工具联动
- CR → 趋势 → 邮件 → 任务 自动化
- 数据流水线

## 数据库新增表

### ai_configs（AI 配置）
- id, user_id, provider, api_key(加密), model, temperature, max_tokens
- created_at, updated_at

### ai_conversations（AI 对话历史）
- id, user_id, session_id, role, content, tokens, created_at

### ai_reports（AI 生成的报告）
- id, user_id, report_type, title, content, data_ref, created_at

## API 设计

### /api/ai/chat
- POST: 发送消息，返回 AI 回复
- 支持流式输出

### /api/ai/config
- GET: 获取 AI 配置
- POST: 保存 AI 配置

### /api/ai/query
- POST: 自然语言查询数据
- Body: { "question": "本周有多少未解决 Bug?" }

### /api/ai/analyze/cr
- POST: AI 分析 CR 数据
- Body: { "data_id": "...", "analysis_type": "attribution|prediction|suggestion" }

### /api/ai/report/generate
- POST: 生成智能报告
- Body: { "report_type": "daily|weekly", "range": "..." }

## 安全设计
- API Key AES 加密存储
- 速率限制（每用户每分钟 20 次）
- Token 用量统计
- 内容安全过滤
