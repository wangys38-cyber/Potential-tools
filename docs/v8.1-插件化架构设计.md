# Potential-tools v8.1「插件化」架构设计

## 版本目标
从"单体工具平台"升级为"可扩展插件生态"，支持第三方开发者通过插件扩展功能。

## 核心架构

```
┌─────────────────────────────────────────────────┐
│                   前端 (Vanilla JS)              │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │ 插件市场 │ │ 插件管理 │ │ 插件 UI 注入点    │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
└────────────────────┬────────────────────────────┘
                     │ REST API
┌────────────────────▼────────────────────────────┐
│              插件核心层 (core/plugin/)            │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │ 加载器   │ │ 生命周期 │ │ 插件 API (SDK)    │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
└────────────────────┬────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────┐
│              插件目录 (plugins/)                 │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │ plugin-a │ │ plugin-b │ │ 第三方插件...     │ │
│  │ backend/ │ │ backend/ │ │                  │ │
│  │ frontend/│ │ frontend/│ │                  │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
└─────────────────────────────────────────────────┘
```

## 开发阶段

### Phase 1: 插件核心框架
- 插件目录结构和描述文件规范 (plugin.json)
- 插件加载器：启动时自动扫描、加载、校验
- 插件生命周期：install → activate → deactivate → uninstall
- 插件 API (SDK)：数据库访问、路由注册、页面注入、工具调用
- 插件权限系统：声明式权限，最小权限原则

### Phase 2: 插件管理系统
- 数据库表：plugins（已安装插件）、plugin_settings（插件配置）
- 后端 API：列表/安装/卸载/启用/禁用/配置
- 前端管理页面：已安装插件列表、状态管理、配置入口
- 插件热加载：无需重启服务即可启用/禁用

### Phase 3: 插件市场
- 插件市场页面：浏览、搜索、分类
- 在线安装：从 GitHub/URL 下载安装
- 插件更新检查和一键更新
- 插件评分和评论

### Phase 4: 生态建设
- 示例插件：3-5 个官方示例插件
- 插件开发 SDK 和文档
- 插件模板生成器
- 插件审核和安全检查

## 插件目录结构

```
plugins/
└── my-plugin/
    ├── plugin.json          # 插件描述文件
    ├── backend/
    │   ├── __init__.py
    │   └── main.py          # 后端入口
    ├── frontend/
    │   ├── index.js         # 前端脚本
    │   └── style.css        # 前端样式
    └── README.md            # 插件说明
```

## plugin.json 规范

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "description": "插件功能描述",
  "author": "开发者",
  "min_app_version": "8.1.0",
  "permissions": ["database", "routes", "pages"],
  "entry": {
    "backend": "backend.main:Plugin",
    "frontend": "frontend/index.js"
  },
  "settings": [
    {
      "key": "api_key",
      "name": "API Key",
      "type": "string",
      "required": true
    }
  ]
}
```

## 插件 API (SDK)

```python
class PluginAPI:
    # 数据库
    def get_db(): ...           # 获取数据库引擎
    def query(sql, params): ... # 执行查询

    # 路由
    def add_route(path, handler, methods): ...  # 注册 API 路由
    def add_page(path, template): ...           # 注册页面

    # 工具调用
    def call_tool(tool_name, params): ...       # 调用内置工具

    # 配置
    def get_settings(): ...                     # 获取插件配置
    def save_settings(settings): ...            # 保存插件配置

    # 日志
    def log(message): ...                       # 记录日志
```

## 权限系统

| 权限 | 说明 |
|------|------|
| database | 数据库只读访问 |
| database_write | 数据库读写 |
| routes | 注册 API 路由 |
| pages | 注册前端页面 |
| tools | 调用内置工具 |
| network | 网络访问 |
| filesystem | 文件系统访问 |

## 安全设计
- 插件沙箱：限制文件系统和网络访问
- 权限声明：插件必须声明所需权限，用户授权后生效
- 代码审计：安装时检查危险操作
- 隔离运行：插件之间数据隔离
- 自动禁用：插件异常时自动禁用并通知
