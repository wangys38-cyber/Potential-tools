# Potential Tools 用户手册

## 概述

Potential Tools 是一站式研发效率工具平台，面向智能硬件研发团队，集成 20+ 工具，覆盖研发分析、文档生成、工具效率和系统管理四大类。

线上地址：https://wangys666.top

## 快速上手

### 注册与登录

1. 访问平台首页，点击右上角「登录」
2. 支持三种登录方式：
   - 账号密码：输入用户名和密码登录
   - 微信 OAuth：使用微信扫码登录
   - 访客模式：无需注册即可体验基础功能（数据不持久化）
3. 首次使用需阅读并同意隐私政策

### 界面导航

- 顶部导航栏：工具搜索、数据同步、主题切换、设置入口
- 首页：按分类展示所有工具，支持搜索和收藏
- 每个工具页面顶部显示当前工具名称

### 主题切换

- 点击导航栏月亮/太阳图标切换明/暗主题
- 支持跟随系统主题自动切换
- 主题偏好随账号保存，换设备自动同步

## 工具使用指南

### 研发分析类

#### CR 问题分析

1. 上传 Jira 导出的 Excel 或 CSV 文件（支持 200MB 大文件分块上传）
2. 系统自动按模块、研发、严重度、状态多维分析
3. 查看研发效率排名、模块健康度、Bug 趋势曲线
4. 点击「AI 根因分析」获取智能分析报告
5. 支持飞书推送和导出 PDF

#### 日志智能根因分析

1. 上传设备日志文件或直接粘贴日志内容
2. 系统自动识别异常模式、构建错误链
3. 匹配相似历史问题（内置 8 类历史问题库）
4. 点击「AI 深度分析」获取根因+修复建议+风险等级

#### 研发知识图谱

1. 从 CR 分析数据一键导入，或手动创建节点和关系
2. 支持 7 种节点类型（Bug/需求/模块/人员/版本/测试用例/风险）
3. 力导向布局可视化，鼠标拖拽平移、滚轮缩放
4. 点击节点查看详情，支持搜索和类型过滤
5. 使用智能问答功能自然语言查询图谱数据

#### 其他分析工具

- **测试报告分析**：上传测试报告 Excel，自动提取测试项、风险评估
- **Bug 趋势看板**：多版本对比、周对比表、热力图、堆叠面积图
- **MTTF 可靠性看板**：设备挂测日志分析，MTTF/MTBF 计算
- **Dashboard 研发健康度**：综合指标概览

### 文档生成类

#### HLD 生成器

1. 上传 OD Excel 需求文档
2. 系统自动为每个 Feature 生成 HLD（含 LLD 级细节）
3. 支持 Mermaid 时序图和状态机
4. 批量 ZIP 下载

#### 软件计划生成器

1. 选择项目类型和起始节点
2. 一键生成完整软件计划时间节点表
3. 甘特图展示，支持 AI 调整建议
4. 支持飞书推送，会议纪要待办自动流转

#### 会议纪要

1. 上传音频文件或直接输入会议内容
2. AI 自动生成结构化会议纪要
3. 待办事项可一键流转到项目计划
4. 支持下载 PDF

#### 其他文档工具

- **智能周报**：基于工作素材 AI 生成结构化周报
- **每日站会助手**：三段式输入，AI 润色，飞书推送，定时提醒
- **项目信息收集**：管理软件项目完整技术规格信息

### 工具效率类

#### IT 翻译器

- 专为 IT 技术文档设计，代码块自动保护
- 内置术语库强制映射，确保翻译一致性

- 支持柱状图/折线图/饼图/散点/雷达/热力图
- 双 Y 轴、标注线，导出 PNG/SVG/CSV
- 图表模板可保存复用

#### 牛马笔记

- Markdown 编辑+实时预览
- 分类标签、全文搜索、模板

- 快捷键支持

## 账号与数据安全

### 数据导出

1. 进入「设置」页面，找到「账号与数据」 section
2. 点击「导出数据」，系统将下载您的全部个人数据为 JSON 文件
3. 包含：用户信息、笔记、分析记录、文档、偏好设置、活动统计

### 修改密码

1. 进入「设置」→「账号与数据」→「修改密码」
2. 输入当前密码和新密码（至少 8 位，含字母和数字）
3. 点击「确认修改」，修改成功后其他设备将自动下线

### 注销账号

1. 进入「设置」→「账号与数据」→「注销账号」
2. 阅读提示，点击「注销账号」按钮
3. 在弹窗中输入密码确认（本地账号）
4. 账号将被标记删除，30 天内可联系管理员恢复，之后永久删除

## 协作功能

### 共享工作空间

1. 在任意工具页面点击「分享」按钮
2. 设置权限（查看/编辑）和有效期（默认 7 天）
3. 生成 8 位分享码和分享链接
4. 协作者通过链接访问，支持评论和实时同步

### 团队协作

- 创建团队，邀请成员加入
- 团队所有者可转让所有权或移除成员
- 团队数据共享，版本历史可追溯

## 飞书推送配置

1. 进入「设置」→「飞书机器人配置」
2. 填写飞书机器人 Webhook 地址和签名密钥
3. 点击「测试连接」验证配置
4. 配置成功后，CR 分析、站会、项目计划等支持一键推送到飞书群
5. 推送历史记录可在设置页查看，支持重发

## AI 配置

1. 进入「设置」→「AI 配置」
2. 选择 AI 服务商（支持豆包/DeepSeek/小米/OpenAI/通义千问/智谱/Kimi/混元）
3. 填写 API Key、API 地址和默认模型
4. 点击「测试连接」验证
5. 配置随账号保存，换设备自动同步

## 常见问题

### 大文件上传失败

- 确认文件大小不超过 200MB
- 检查网络连接，分块上传支持断点续传
- 如遇网关限制，尝试拆分文件

### AI 功能无响应

- 检查「设置」→「AI 配置」中的 API Key 是否正确
- 点击「测试连接」验证 API 可用性
- AI 请求超时时间为 200 秒，复杂分析可能需要较长时间

### 数据不同步

- 确认已登录账号（访客模式数据不持久化）
- 点击导航栏「同步」按钮手动触发同步
- 检查网络连接

### 暗色模式图表显示异常

- 图表已自动适配暗色主题
- 如遇异常，刷新页面即可
