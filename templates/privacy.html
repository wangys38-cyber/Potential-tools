隐私政策

最后更新：2026年8月25日

1. 我们收集的信息

为了向您提供服务，我们可能收集以下信息：

  • 账号信息：用户名、邮箱、密码（加密存储）、头像
  • 使用数据：您创建的笔记、分析记录、文档、偏好设置
  • 登录信息：登录时间、IP地址、浏览器User-Agent（用于安全审计）
  • OAuth信息：通过飞书/Google/微信登录时，获取您的昵称、邮箱、头像

2. 信息的使用

我们收集的信息仅用于：

  • 提供和维护工具集的各项功能
  • 保存您的分析记录和个人设置
  • 账号安全防护（登录异常检测、操作审计）
  • 改进产品体验（匿名统计分析）

3. 数据存储与安全

  • 密码使用 Werkzeug PBKDF2 算法加盐哈希存储，不可逆
  • API Key、Webhook Secret 等敏感数据使用 Fernet (AES-128) 加密存储
  • 所有数据库查询使用参数化查询，防止 SQL 注入
  • 用户数据按用户 ID 隔离存储，互不可见
  • 登录失败5次自动锁定15分钟，防止暴力破解
  • 操作日志保留90天，用于安全审计

4. 您的权利

您对个人数据享有以下权利：

  • 数据导出：可通过设置页面导出您的全部数据为 JSON 格式
  • 账号删除：可申请删除账号，数据将在30天内彻底清除（期间可恢复）
  • 数据更正：可随时修改个人资料和偏好设置
  • 访问控制：可查看您的登录记录和操作审计

5. 第三方服务

我们使用以下第三方服务，其隐私政策另行适用：

  • 飞书 OAuth 登录（获取昵称、邮箱、头像）
  • Google OAuth 登录（获取昵称、邮箱、头像）
  • 微信 OAuth 登录（获取昵称、头像）
  • AI 服务提供商（您主动配置的 API Key，数据传输至对应服务商）

6. Cookie 使用

我们使用 Session Cookie 维持您的登录状态。Cookie 仅包含会话标识，不包含个人信息。登录状态默认保留24小时，勾选"记住我"可延长至7天。

7. 数据保留

  • 账号数据：账号存续期间保留，删除后30天彻底清除
  • 登录尝试记录：保留24小时
  • 审计日志：保留90天
  • 活动记录：保留90天
  • 数据备份：保留7天每日备份 + 4周每周备份

8. 政策更新

我们可能适时更新本隐私政策。重大变更将通过站内通知或邮件告知您。继续使用服务即表示您同意更新后的政策。
